# Bookworm

Bookworm allows users to add, view, and delete books, storing information such as title, author, genre, rating, review, and creation date. Data is persisted locally using SwiftData.

## Tech

- Swift
- SwiftUI
- SwiftData

## Features

- Add new books
- Delete books from the list
- Store book details (title, author, genre, rating, review, creation date)
- Persist data locally using SwiftData
- Basic form validation (title and author required)
- Highlight low-rated books (1-star shown in red)
- Sort books by creation date (newest first)
